## Step 2：解讀財報關鍵數據

台股特色：半年報（年報）為完整財報，每季另有季報揭露。月營收每月公布（營收成長率最重要）。

### 營收與獲利

| 指標 | 說明 | 計算方式 |
|------|------|---------|
| 月營收（百萬元）| 每月公布，反映淡旺季 | 直接取用 |
| 累計營收（百萬元）| 年初至本月底累計 | 直接取用 |
| YoY（年增率）| 月營收同期比 | (本月 / 去年同期 - 1) × 100% |
| 毛利率 | 毛利 / 營收 | (毛利 ÷ 營收) × 100% |
| 營益率 | 營業利益 / 營收 | (營業利益 ÷ 營收) × 100% |
| 淨利率 | 稅後淨利 / 營收 | (稅後淨利 ÷ 營收) × 100% |
| EPS（元）| 每股盈餘 | 稅後淨利 ÷ 流通股數 |
| ROE | 股東權益報酬率 | 淨利 ÷ 股東權益 × 100% |

### 營收組成（分項營收）

台股公司需揭露「產品別」或「地區別」營收，可從季報找到。

| 分項 | 營收佔比 | 本季 vs 去年同期 |
|------|---------|----------------|
| 例如：AI 應用 | 35% | +20% YoY |
| 例如：智慧手機 | 25% | -10% YoY |

### 估值指標

| 指標 | 計算 | 說明 |
|------|------|------|
| P/E（本益比）| 股價 ÷ EPS | 台股常用，合理的歷史區間判斷高低 |
| P/B（股價淨值比）| 股價 ÷ 每股淨值 | 景氣循環股參考 |
| 現金股利殖利率 | 現金股利 ÷ 股價 | 年化殖利率 |
| EV/EBITDA | 企業價值 ÷ EBITDA | 產業比較用 |

## Step 3：建立因果鏈框架

台股獨有邏輯：
- **半導體供應鏈**：終端需求（消費電子、AI）→ IC 設計 → 晶圓代工 → 封測
- **iPhone 供應鏈**：蘋果新機發表 → 台灣供應商營收季節性
- **AI 伺服器供應鏈**：輝達 GPU → 散熱/PCB/機殼/電源

```
[終端需求（如：AI 伺服器出貨）
         ↓
 晶圓代工（台積電、先進製程）
         ↓
 IC 設計（聯發科、譜瑞-KY 等）
         ↓
 封測（日月光、力成等）
         ↓
 電源/散熱（台達電、光寶科等）
         ↓
 組裝（鴻海、廣達等）]
```

**識別關鍵變量**（以台積電為例）：

| 關鍵變量 | 觀察對象 | 正常信號 | 警訊信號 |
|---------|---------|---------|---------|
| AI 需求 |輝達 GPU 出貨量、CoWoS 封裝產能 | 先進製程滿載 | 產能利用率下滑 |
| 先進製程報價 | 3nm/5nm 先進製程價格趨勢 | 價格持平或上升 | 成熟製程降價 |
| 毛利率 | 台積電毛利率指引 | 維持 53-55%+ | 往下偏離指引 |
| CapEx | 年度資本支出指引 | 持平或上升 | 大幅削減 |
| 客戶分布 | Apple/AMD/NVIDIA/Qualcomm 佔比 | AI 客户佔比提升 | 单一客户過度集中 |
| 地緣政治 | 美國對中設備出口管制 | 管制持續，TSMC 穩定獲份額 | 管制放鬆或收緊 |

## Step 4：三層錯誤框架分析

### 第一層：價格錯誤（PE 被壓制）

台股特色：本益比受「法人籌碼」與「匯率」影響大。

| 觀察 | 結論 |
|------|------|
| 台幣升值 vs 貶值對 EPS 影響（電子業出口為主）| 匯率風險是否已反映在股價？|
| 目前 P/E vs 5 年平均 P/E | 偏高 / 合理 / 偏低？ |
| 全球同業 P/E（日本、韓國半導體）| 相對估值高低？ |

### 第二層：關鍵變量改變

| 關鍵變量 | 上一季變化方向 | 本季變化方向 | 是否偏離預期？ |
|---------|--------------|------------|--------------|
| 月營收 YoY | | | |
| 毛利率變化 | | | |
| 產品組合（AI 相關佔比）| | | |
| CapEx 計劃變化 | | | |

### 第三層：因果鏈斷裂測試

> **核心問題：「我投資這支股票的核心前提，假設現在還成立嗎？」**

## Step 5：買入前三個問題

根據台股特性調整：

| 問題 | 答案（台股版）|
|------|--------------|
| **問題一：我為什麼要買這支股票？** | 明確的投資邏輯（代工景氣/AI 需求/技術領先/股利殖利率等）|
| **問題二：我重點看哪三個關鍵數據？** | 設定 3 個可量化指標（如：月營收 YoY > 15%、毛利率維持 X%、AI 營收佔比提升至 Y%）|
| **問題三：出現什麼情況後我要承認判斷錯誤？** | 設定觸發條件（如：月營收連續兩季 YoY < 0%、競爭對手技術超車、關鍵客戶流失）|

## Step 6：台股資料讀取優先順序

1. **公開資訊觀測站**（mops.twse.com.tw）：搜尋「公開資訊觀測站 + [代碼] + 財報」
2. **Goodinfo**（goodinfo.com）：直接讀取股票頁面（內含歷史 EPS、月營收、股利）
3. **MoneyDJ**（moneydj.com）：搜尋「[公司名] 財報 分析」
4. **Yahoo 奇摩股市**（tw.stock.yahoo.com）：快速取得日成交資料
5. **Google 新聞**：搜尋「[公司名] OR [代碼] 最新」，覆核財報數據
