# 股票財報分析 workflow

> 當使用者提供股票名稱（或代碼）時，啟動本 workflow。上網搜尋最近 4 季財報（10-Q / 10-K）、財報電話會議紀錄、資本市場oday（CMD / Investor Day）、重大新聞，完成與「價值投資方法論」框架對齊的分析報告。

---

## Step 0：接收輸入

使用者輸入格式可能為：
- 股票名稱：「輝達」、「Palantir」
- 股票代碼：「NVDA」、「PLTR」
- 兩者混合：「輝達（NVDA）」

**解析規則：**
- 嘗試映射至已知代碼（如輝達→NVDA）
- 若未知，視為名稱，直接進入搜尋

---

## Step 1：搜尋財報資料

對每支股票，搜尋以下資料（優先使用英文關鍵字）：

### 1.1 季度財報（10-Q）

```
site:sec.gov OR site:investor.related-company.com "[TICKER]" "10-Q" "2025"
```

### 1.2 年度財報（10-K）

```
site:sec.gov "[TICKER]" "10-K" "2025" annual report
```

### 1.3 財報電話會議紀錄（Earnings Call Transcript）

```
"[TICKER]" "Q3 2026" earnings call transcript
"[TICKER]" "second quarter 2026" earnings
```

### 1.4 資本市場日（CMD）

```
"[TICKER]" "Investor Day" 2026 OR "Capital Markets Day" 2026
```

### 1.5 近期重大新聞

```
"[TICKER]" OR "[公司名]" earnings revenue guidance 2026
"[TICKER]" OR "[公司名]" CEO CFO statement Q3 2026
```

### 1.6 營收指引（Revenue Guidance）

```
"[TICKER]" "Q4 2026" revenue guidance raised OR lowered
"[TICKER]" annual revenue forecast 2026 2027
```

**優先順序：**
1. 最近一期 10-Q / 10-K 全文
2. 該季財報電話會議紀錄（最佳口語化表達）
3. 該季營收新聞稿（Press Release）
4. 資本市場日簡報（如有）
5. 分析師覆蓋（Seeking Alpha、AlphaStreet、Benzinga）

---

## Step 2：解讀財報關鍵數據

從搜尋到的文件中，提取並記錄：

### 營收與獲利

| 指標 | 最近一季 | 前一季 | 去年同期 | 年增率 |
|------|---------|--------|---------|--------|
| 營收（Revenue） | | | | |
| 毛利率（Gross Margin） | | | | |
| 營業利益率（Operating Margin） | | | | |
| 淨利率（Net Margin） | | | | |
| EPS（稀釋） | | | | |
| Free Cash Flow（FCF）| | | | |

### 營收組成（Revenue Breakdown）

- 各業務線 / 地區 / 產品線營收佔比
- 哪些業務成長最強？哪些低於預期？

### 前瞻指引（Forward Guidance）

- 下季 / 全年營收指引（數字與年增率）
- 是否上調或下調？幅度多少？
- CEO / CFO 在電話會議中對未來的重點表述

### 關鍵變量（Key Variables）—— 由分析師自行識別

根據公司業務性質，識別 3-7 個驅動股價的關鍵變量，例如：

| 公司類型 | 關鍵變量範例 |
|---------|-------------|
| AI / 半導體 | CapEx 趨勢、GPU 需求、CoWoS 封裝、先進製程產能 |
| 雲端服務 | 雲端營收增速、Marginal revenue per customer、客戶留存率 |
| 企業軟體 | ARR / RPO 成長、NDR（Net Dollar Retention）、FCF margin |
| 電商 | GMV、活躍買家數、Take rate |
| 金融科技 | 存款增速、NIM、壞帳率 |

---

## Step 3：建立「因果鏈」框架

參考價值投資方法論，建立該公司股價驅動因素的因果鏈：

```
[最上游客觀察]
         ↓
[中游產能 / 訂單]
         ↓
[下游需求]
         ↓
[公司營收]
         ↓
[EPS 成長]
         ↓
[股價長期表現]
```

**操作方法：**
1. 識別該公司所在產業的最上游催化劑（如：AI 應用活躍 → 資料中心擴張 → GPU 需求 → 輝達訂單）
2. 確認公司在因果鏈中的位置（上、中、下游）
3. 找出因果鏈中**最脆弱的環節**（容易失效或被破壞的環節）
4. 標記目前各環節的狀態：✅ 正常、⚠️ 放緩、❌ 斷裂

---

## Step 4：三層錯誤框架分析

### 第一層：價格錯誤（PE 被壓制）

| 觀察 | 結論 |
|------|------|
| 近期是否有加息、宏觀恐慌、政治因素影響 PE？ | 是否需要認虧？ |
| 目前 PE vs 歷史平均？ | PE 偏貴 / 合理 / 偏低？ |
| 目前 PE vs 同業平均？ | 相對估值高低？ |

### 第二層：關鍵變量改變

| 關鍵變量 | 上一季變化方向 | 本季變化方向 | 是否偏離預期？ |
|---------|--------------|------------|--------------|
| 營收增速 | | | |
| 毛利率變化 | | | |
| 客戶流失 / 新增情況 | | | |
| 競爭格局變化 | | | |
| ... | | | |

### 第三層：因果鏈斷裂測試

> **核心問題：「我當初投資這支股票的核心前提，假設現在還成立嗎？」**

逐條檢驗：
1. 這個核心假設是什麼？（盡可能用具體一句話描述）
2. 這個假設的證據，目前是加強了還是削弱了？
3. 若假設已斷裂，你的應對是什麼？

---

## Step 5：買入前三個問題（輸出）

根據財報分析，給出：

| 問題 | 答案 |
|------|------|
| **問題一：我為什麼要買這支股票？** | 明確的投資邏輯與目標價邏輯 |
| **問題二：我重點看哪三個關鍵數據？** | 設定 3 個可量化的監控指標（如下季 EPS、毛利率年增率、CapEx 等）|
| **問題三：出現什麼情況後我要承認判斷錯誤？** | 設定觸發條件（如：連續兩季 EPS 低於預期 20% 以上、關鍵變量連續惡化）|
