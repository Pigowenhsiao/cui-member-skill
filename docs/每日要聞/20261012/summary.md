**市場影響：**
週末油價竄高後回落，關鍵因素：
1. **川普干預：** 10月9日川普宣布與普丁談判柴油供應，美國對俄羅斯發出臨時進口許可

   - 10月4日美國柴油均價達每加侖 **6.28 美元**（歷史高檔）
   - 卡車運輸、農業機械、家庭取暖成本上升直接威脅川普基本盤
2. **國際能源署（IEA）署長比羅爾：** 要求成員國評估追加釋放柴油儲備
3. **沙烏地輸油管道擴建：** 7-8週內可通過天然氣管道每日輸送120萬桶石油；2-3年內提升至1000萬桶/日
4. **墨西哥灣颶風緩解：** 油氣公司已恢復生產
