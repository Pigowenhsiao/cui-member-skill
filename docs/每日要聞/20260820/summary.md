## 一、美軍打通霍爾木茲海峽
### 1.1 軍事進展
- 美軍已在霍爾木茲海峽開闢秘密航道（靠近阿曼一側）
- 水下無人設備清理100多個疑似水雷
- 每天護航15-24艘油輪通過
- 每日約1000萬桶石油可以運出波斯灣

### 1.2 瑞銀證實
- 瑞銀研究發現：每日通過暗流運出的石油約500-600萬桶
- 與美軍公佈數據有一定差距，但確認事件真實性
- 路透社衛星圖像亦證實有油輪關閉AIS信號穿越海峽

### 1.3 對油價的影響
- 供給擔憂緩解，布油從高位回落
- 伊朗對霍爾木茲的控制力下降
- 這可能是伊朗態度軟化的主要原因

## 二、加拿大強硬反擊
### 2.1 報復性關稅
- 加拿大政府宣佈對約2000億美元美國商品徵收報復性關稅
- 涉及約700種商品，稅率分為15%/25%/50%三檔
- 9月8日起生效
- 配套：75億加元援助計劃支持受影響企業和工人

### 2.2 川普回應
- 川普威脅要將安大略湖改名為「美國湖」
- 美國考慮進一步報復加拿大
- 貿易戰進一步升級

### 2.3 主持人分析
- 加拿大的補貼操作：社會主義式干預（政府補貼受損企業）
- 川普貿易戰沒有贏家，只有程度不一的損失
- 對全球供應鏈和消費者信心均有負面影響

## 三、貿易戰對全球市場的影響
### 3.1 美元貶值交易降溫
- 美伊局勢緩解 + 加拿大反擊
- 市場避險情緒有所降溫
- 比特幣和黃金漲幅收窄

### 3.2 美股走勢
- 美元貶值交易暫停，科技股出現分化
- 半導體板塊承壓：內存、光通信成重災區
- 納指連跌7個交易日（2022年9月以來最長連跌）
- 金融、消費品等價值股抗跌

### 3.3 市場情緒逆轉
- 資金從科技股輪動至防禦性股票
- 油價回落緩解通脹擔憂
- 美債收益率維持高位但壓力有所緩解
