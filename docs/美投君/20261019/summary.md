## 一、馬克斯（Marx）vs 華爾街：AI 泡沫辯論

### 馬克斯的核心觀點
前 D.E. Shaw 聯席董事長 **馬克斯**（Marx）提出三個「真正泡沫」的特征：
1. 非理性繁榮
2. 魯莽投資
3. 投資者對風險回報「不計較」

**結論**：現階段市場雖然討論泡沫，但投資者持續檢視估值與融資風險，並非不計代價——距離真正泡沫尚有一段距離。

### 估值支撐論據
- 標普與納指 **遠期市盈率** 今年以來反而下降（盈利增速高於股價漲幅）
- 對比 1999 年互聯網泡沫：泡沫頂峰前一個月，市值最大五家科技公司平均遠期 PE 達 **65 倍**；現今市值最大五家僅 **23 倍**

### 質疑觀點（麥克爾·若克 / Michael Rook）
- **席勒 PE**（10 年經通脹調整均值）目前約 **41 倍**，距離 1999 年歷史高點 44 倍僅剩一小段
- 大科技不斷增加發債用於 AI 建設→企業槓桿上升→終將壓低估值
- 新變種（SPV）融資模式：客户提供資金讓客戶購買自己的產品，一旦客戶融資能力惡化，供應商銷售與投資回報可能雙雙受損

### 美投 CEO Jason 的結論
馬克斯的判斷較為合理：
- 市場情緒已明顯轉弱（與 1999 年狂熱不同）
- 但 AI 需求仍在增長、企業盈利持續改善
- **好的基本面公司**當前估值仍有吸引力
- **風險在外部融資環境**：一旦部分公司出現融資困難，恐慌可能蔓延整個 AI 板塊
- 就像 CoreWeave 案例：大科技有廣告、雲端等持續現金流支撐，小雲只能靠發債——脆弱得多

## 二、高盛上調 CoreWeave 評級：散戶該跟嗎？

### 背景事件
CoreWeave 上週因債務問題遭大幅拋售，無擔保債券殖利率一度突破 15%，信用違約交換（CDS）價格創歷史高位。

### 高盛上調評級：中性 → 買入，目標價 $106

**三大理由：**

| 理由 | 內容 |
|------|------|
| **執行力優秀** | 對比 300+ AI 算力供應商排名，CoreWeave 執行力排前 2%；同樣成本提供算力比同業高約 20% |
| **融資壓力被高估** | 主要靠「遞延提款定期貸款」（以 GPU + 已簽訂客戶合約抵押），而非新發债券；銀行看的是「房子與租約」的還款能力，非公司信用評級 |
| **收費能力被低估** | 已從 7 月起提價 25%、10 月再提價 10%；長期合約每 GPU 每、年收入有望從 1,000 萬升至 1,300 萬美元 |

### 高盛模型測試

| 每 GPU 年收入 | 項目回報率 |
|-------------|-----------|
| 1,000 萬美元 | 6.3%（低於資金成本 11.8%，不划算）|
| 1,300 萬美元 | 15%（可接受）|
| 含 GPU 殘值（第 6 年）| 20–25% |

### Jason 的質疑：**模型假設過於樂觀**

- 核心問題：**融資成本假設**太樂觀——美光集週期未結束 + 大科技發債尚未全面開啟
- **真實情境**：融資成本很可能繼續上升，而非停在 10%
- 按高盛敏感性分析：即使每 GPU 收入升至 1,300 萬美元，資金成本若升至 11% 就不划算
- **目標價 $106 對應樂觀情境，非基準情境**
- **Meta** 將裁報發布日提前一週，正是為了提早準備發債——信號：大家都想搶在資金成本上升前低價發債

## 三、大摩上調亞馬遜（Amazon）目標價至 $350

**分析師 Brian Nuick 的三大理由：**

| 理由 | 內容 |
|------|------|
| **AWS 增長潛力被低估** | 市場預期未來兩季 AWS 增速僅 38%/39%，但大摩預計 2027 年全年增 **47%**；與 Anthropic 收入相關性高，是重大缺乏計 |
| **AI 代理購物機遇** | Amazon 電商基礎設施領先，年底購物季將是觀察窗口 |
| **實體 AI** | 物流中心機器人自動化，2017 年更多採用將進一步釋放產能 |

### Steven 分析師補充
非常認可大摩觀點：
- AWS 與 Anthropic 收入相關性大（Anthropic 是 AWS 最大客戶之一）
- 自研 AI 晶片銷售 + 產能在下半年快速釋放
- 個人預期 AWS 大概率可維持好幾季高增長

## 四、馬斯克宣布向全美兒童送 SpaceX 股票

### 背景
Anthropic 週六宣布拿出 5% 股份（約 2 兆美元）成立公益基金；馬斯克在 X 上留言建議「不如直接送給大眾」，今日付諸行動。

### 計劃內容
- 對象：全美 18 歲以下兒童（約 7,200 萬人）
- 方式：每人一股 SpaceX（約佔馬斯克持股的 1.5%）
- 總價值：約 **105 億美元**（按上週五收盤價）
- 目前停在口頭承諾階段，尚未有具體發放時間與方式

### 對 SpaceX 現有股東的影響：**基本無影響**

| 影響維度 | 分析 |
|---------|------|
| 股權稀釋 | 否——馬斯克動用的是自己持有的股份，非公司增發 |
| 控制權 | 影響有限——馬斯克持有的是 B 類股（10 票），送出的是 A 類股（1 票），投票權影響極小 |
| 稅務優惠 | 馬斯克可通過捐贈至慈善基金會節省巨額資本利得稅（取決於最終採用何種架構）|

### 馬斯克過去支票紀錄
- 承諾給 OpenAI 的 10 億美元，最後只到帳約 3,800 萬
- 承諾給聯合國世界糧食計劃署的 61 億美元，也未完全兌現
- **結論**：明年見分曉
