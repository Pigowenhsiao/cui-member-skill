## 主要風險

| 風險 | 說明 |
|------|------|
| **AI 雲端競爭激烈** | AWS/Azure/Google 三強壟斷，OCI 市佔率仍小但增速驚人 |
| **大型併購整合風險** | Cerner（$283億）收購後整合挑戰仍在 |
| **Larry Ellison 年齡** | 創辦人高龄，接班規劃不明確 |
| **中國市場限制** | Oracle 在中國的雲端業務受地緣政治影響 |
| **AI GPU 供應瓶頸** | NVIDIA GPU 供不應求可能限制 OCI 成長速度 |
| **SaaS 市場飽和** | Cloud Apps 增速放緩至 10%，面臨成長天花板 |
