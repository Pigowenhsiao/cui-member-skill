# 中美AI供應鏈競爭、中期選舉與中國經濟數據｜小翠時政財經

**日期**：2026年8月17日（美東時間）  
**影片**：https://www.youtube.com/watch?v=Zw6CUueiFxA

## 重點

- **美伊與供應鏈陣營**：荷姆茲海峽通行量仍低於戰前，伊朗與美國立場僵持。路透社報導美國正籌組AI供應鏈聯盟Pax Silica，涵蓋晶片、資料中心、關鍵礦物及出口管制；主持人稱若盟友參與，可能被要求降低與中國AI供應鏈合作，相關安排仍在形成中。
- **美國消費與中期選舉**：7月零售銷售月減0.6%，汽車、網路銷售等分項走弱；密西根大學消費者信心指數為51，一年通膨預期4.3%。主持人認為高油價及生活成本正壓縮消費，尤其影響低收入家庭。她回顧中期選舉前標普500常有季節性回落，但強調歷史平均不代表今年必然下跌。
- **AI支出與日本經濟**：節目引用企業資料稱大型企業AI支出迅速增加，但各企業使用程度差異很大。日本第二季GDP年化增長1.1%，低於預期；企業設備投資下滑，消費仍弱，出口則受AI需求支撐。主持人認為日本經濟與物價承受輸入成本壓力，升息未必能解決。
- **財報與融資模式**：波克夏披露新增Alphabet持股，並買入航空及房屋建築商股票、減持美銀。NVIDIA與OpenAI資料中心計畫涉及大規模算力與長期租約；主持人提醒公開報導中的供電規模、租約及融資安排須區分已公布事項與規劃。她比較Nebius、CoreWeave等算力業者偏短期、高溢價合約，與AWS較長年限合約，認為前者短期收入可能較高，但價格回落時風險亦較大。
- **中國經濟數據**：7月規模以上工業增加值年增4.5%，低於預期；社會消費品零售總額年增0.6%，低於預期；城鎮調查失業率5.2%，高於前值；固定資產投資年減6.7%。主持人認為數據顯示內需疲弱，但指出政策刺激規模與內容仍不確定。
