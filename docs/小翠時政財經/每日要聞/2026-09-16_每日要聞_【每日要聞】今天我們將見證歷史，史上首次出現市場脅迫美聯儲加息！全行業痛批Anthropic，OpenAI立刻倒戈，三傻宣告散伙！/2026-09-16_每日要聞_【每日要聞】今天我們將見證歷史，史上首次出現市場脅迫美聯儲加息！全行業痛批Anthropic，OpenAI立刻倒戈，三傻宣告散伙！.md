# 【每日要聞】今天我們將見證歷史，史上首次出現市場脅迫美聯儲加息！全行業痛批Anthropic，OpenAI立刻倒戈，三傻宣告散伙！

**日期：**2026-09-16（美東）  
**影片：**https://www.youtube.com/watch?v=oqHAV1X1zgc

## 內容摘要
本集在美聯儲議息前討論市場對加息的高度定價及主席沃什的政策取捨。主持人認為若為穩定市場而跟隨市場加息，將形成政策受市場脅迫的罕見局面；她個人仍傾向沃什不支持加息，但不確定投票結果。節目另分析財長貝森特國會聽證、美國與中國及伊朗相關金融議題、韓國半導體供應鏈與Intel轉型，以及AI安全爭論中OpenAI與Anthropic的分歧。節目末有觀眾問答，談到股票與投資方式。

## 重點整理
- **沙特原油替代運輸：**沙特嘗試繞過受損管道，透過阿曼附近船對船轉運供應亞洲客戶；紅海管道或數週無法恢復，沙特仍與胡塞武裝交火。主持人認為替代供應消息令油價回落。
- **美聯儲決策與市場定價：**高盛估計美聯儲可能加息25個基點，但認為這不是由紮實經濟基本面推動，而是受市場定價牽引；建議聲明只作最低限度修改、避免前瞻指引。主持人回顧沃什主張市場價格只能作政策輸入，不能變成指令；她認為若按經濟基本面本不應加息，自己傾向沃什不投加息票，並指出長端利率與短端借款成本、民生及財政壓力彼此牽制。
- **貝森特國會聽證：**貝森特稱油價衝擊及財政赤字均影響長端利率，並稱美國曾買入日圓、交易獲利；他把「強美元」解釋為全球資本流向美國。主持人指出他將與何立峰會談稀土、貿易及伊朗等議題；貝森特反對給AI公司責任豁免、支持開源AI，並稱財政部研究向民眾發放5,000美元但仍需國會批准，主持人對其可行性存疑。
- **AI安全與公司利益：**OpenAI的Sam Altman與Anthropic保持距離，反對把工程風險推演成末日論；OpenAI政策負責人稱公司間原可自行討論安全，無須另求反壟斷豁免。主持人認為AI安全應有測試與責任制度，但反對以安全之名建立壟斷門檻。微軟CEO納德拉區分傳統軟件漏洞與長期多智能體的新風險，主張以因果分析、監控和審計處理；他亦主張企業不要依賴單一模型供應商。Anthropic一邊呼籲放緩、一邊簽下澳洲資料中心租約，主持人以此指出言行矛盾。
- **半導體與企業動態：**SK海力士同意把員工現金分紅比例提高至50%，降低罷工風險；路透報導其探索與英特爾在美國合作生產記憶體，但尚未確認計畫。英特爾CEO陳立武稱CPU供應只能滿足約一半需求，18A已進入大量生產、14A進展順利；他亦坦言公司過去忽視客戶、內部透明度與良率需改善。主持人認為管理改革與需求是觀察重點。
- **中國與北美供應鏈：**美國向墨西哥施壓，要求AI伺服器及相關硬體達到更高北美本地製造比例，避免中國零件僅在墨西哥組裝後享有低關稅待遇；若規則落地，中國及台灣伺服器供應鏈均可能受影響。中國央行行長潘功勝則稱融資結構轉型，未來科技企業更多透過股權與債券直接融資，傳統房地產與基建貸款占比下降。

## 小翠讀評
- **美股配置：**觀眾詢問谷歌與Figma能否加倉。主持人稱Figma屬小型高風險標的，較適合小倉位視作「彩票」；她認為谷歌低於350美元仍可買入。主持人另稱美股整體估值受宏觀壓力壓低，並以約19.5倍PE對比高EPS增長，認為估值偏低。
- **其他觀眾提問：**主持人認為亞馬遜是大型雲端業者、基本面不錯但當時價格不算特別便宜；Meta近期反彈與此前估值較低、業務進展及新模型改善預期有關。她亦稱在中國可考慮納指ETF但須留意溢價，並提醒依風險承受能力配置。
- 以上為節目中對觀眾問題的回應，不構成個人化投資建議。
