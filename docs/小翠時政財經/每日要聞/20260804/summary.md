# 中國出境限制新規、美國光模組禁令傳聞與科技股財報｜小翠時政財經

**日期**：2026年8月4日（美東時間）  
**影片**：https://www.youtube.com/watch?v=nDRLXq_rQM4

## 重點

- **美伊與荷姆茲海峽**：財長貝森特稱，美伊海峽協議最快週二或週三可能達成。當時仍在協商，伊朗與阿曼討論臨時航道安排，進入波斯灣的船隻走伊朗控制航道，離港船隻走阿曼一側；伊朗提出收費，美國否認會收費。阿曼附近有貨船遭不明彈射物擊中，責任尚未確認。消息帶動油價回落、美股上漲。
- **軍火與經濟數據**：美軍戰斧巡弋飛彈庫存消耗近半，愛國者攔截彈約消耗65%，THAAD庫存較戰前減少至少38%。五角大廈與洛克希德馬丁等業者達成30億美元擴產框架。7月ISM製造業PMI為55.6，為2022年5月以來高點；就業指數也恢復擴張。
- **美國消費分化**：麥當勞美國同店銷售年增0.8%，低於預期。主持人認為低收入消費者受生活成本擠壓，連平價餐飲消費也減少；高收入族群則仍有消費能力，呈現K型分化。她因此不看好消費股，並認為此時升息會加重低收入者壓力。
- **能源與記憶體**：BP第二季調整後利潤57.3億美元，年增144%。主持人認為若利潤來自市場供需，不應只以道德理由要求企業降價。另有報導稱三星、SK海力士與美光2027年DRAM、HBM產能已分配完畢；她認為市場對記憶體景氣持續時間過度悲觀，但仍需留意股價與估值。
- **科技與中國政策**：節目討論Palantir第二季營收年增93%、美國商業業務年增149%，主持人看好其企業AI平台與結果導向收費，但指出估值偏高。蘋果與OpenAI就前蘋果員工是否帶走商業機密互相指控，OpenAI公開聊天紀錄反駁，主持人認為雙方各有待釐清之處。路透社報導美國FCC正研議限制中國資料中心關鍵設備，可能涉及高速光模組；尚非已生效禁令。中國國務院841號令於7月22日簽署、9月15日施行，整合出境限制規定，主持人擔心適用範圍與邊境裁量權擴大。
