# 中國整頓LOF、波克夏轉為淨買入與美股財報｜小翠時政財經

**日期**：2026年8月10日（美東時間）  
**影片**：https://www.youtube.com/watch?v=C93zHuAtO8U

## 重點

- **美伊僵局與宏觀**：上週所稱的美伊協議尚未達成，雙方仍透過中間人聯絡；美國維持海上封鎖，油價回升。主持人認為川普希望以海峽重新開放作為退場條件，可能弱化原先要求伊朗放棄核計畫的目標。她提醒本週市場關注美國CPI。
- **風險資產與政策訊號**：標普500上週創新高，風險資產資金流入增加。白宮經濟顧問哈賽特稱通膨降溫、經濟仍強，若自己是聯準會官員會維持利率或降息。主持人認為川普政府對不降息的接受度提高；並解讀摩根士丹利提出的「非對稱縮表」構想，認為財政部與聯準會可能協調管理流動性。
- **亞洲與中國市場**：主持人談及中國LOF基金因場內溢價及外匯額度限制而面臨整頓或退市，認為此事反映監管及外匯額度受限，不單是投資者保護。節目未稱所有LOF已正式退市。
- **波克夏投資**：波克夏第二季淨買入約200億美元股票，終止連續三年多淨賣出；新增或加碼Google、房屋建築商Taylor Morrison等，另回購自身股票。主持人視為投資情緒改善的訊號，但指出仍持有大量現金。
- **科技公司與AI基建**：台積電7月營收年增44.7%。英特爾計畫增發普通股以籌措資金，主持人將其視為股權融資與擴大投資的安排。節目也談到SpaceX財報前股價與解禁、NVIDIA投資資料中心電力公司，以及資料中心融資和GPU殘值擔保如何降低投資人對設備折舊的疑慮。
