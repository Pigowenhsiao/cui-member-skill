# 【每日要聞】伊朗制裁與美國財政困境：庇護簽證、對中關稅、日本財政與市場觀察

**日期**：2026-08-25  
**影片**：https://www.youtube.com/watch?v=rC2rH7zRV-0

## 內容摘要
節目分析美國對伊朗新一輪制裁與對中國大型銀行的暫緩處理，並討論川普政府重新審查庇護案件、考慮提高對中關稅，以及貝森特處理美債收益率的有限空間。主持人另談日本財政壓力、美國半導體投資與中國境外投資監管，對政策與個股觀點均屬節目評論。

## 重點整理
- 美國宣布對約60個涉伊朗實體、個人及船舶制裁，擴大次級制裁範圍，涉及數位資產、科技、黃金、航空與航運；各國整改期限未公開。
- 中國大陸及香港部分企業、個人列入制裁名單，但沒有大型銀行遭制裁。主持人認為，美國不願因制裁伊朗而讓中國遭全面排除於美元體系，也考量習近平訪美安排。
- 美國政府據報重新審查以旅遊簽證入境後申請庇護者的案件，涉及 B1、B2 簽證；主持人提到可能影響約20萬人，也承認可能誤傷。
- 彭博報導川普政府考慮以產能過剩為由，對中國商品加徵7.5%關稅，可能作為川習會前談判籌碼；節目將此視為考慮中的方案，而非已落地政策。
- 貝森特稱財政部將照計畫拍賣各期限國債，擴大回購最快9月10日開始，當時尚未買入債券；迷你版支出整頓計畫亦未公布。其恩師德魯肯米勒批評以政府干預壓低長債收益率，認為收益率反映通脹、債務及市場需求。
- 主持人認為貝森特想以強硬訊號嚇退空頭、爭取時間，並等待 AI 拉動 GDP；成敗仍取決於經濟數據及政府能否控制赤字。
- 日本2027財年償債本金與利息估計達36.6兆日圓、年增約17%，約占當年稅收八成以上的一大部分；下一年度預算申請超過130兆日圓。主持人引述高盛預測，日本利率可能升至1.75%。
- 美國半導體股近期調整，納指連跌七個交易日；主持人提及佩洛西買入英特爾，以及記憶體成本推高亞馬遜 Echo 音箱價格。
- 中國人民日報文章承認投資、房地產及地方債壓力，強調結構性支持；主持人解讀為短期不會有大規模增量刺激。節目另稱發改委新規將居民個人境外投資納入備案，企業境外投資須提前申報。
- 節目引用路透報導：西沙壓公島出現疑似雷達設施，附近陵陽礁填海工程包含深水港、碼頭與疑似機場跑道；雷達用途仍未獲確認。
