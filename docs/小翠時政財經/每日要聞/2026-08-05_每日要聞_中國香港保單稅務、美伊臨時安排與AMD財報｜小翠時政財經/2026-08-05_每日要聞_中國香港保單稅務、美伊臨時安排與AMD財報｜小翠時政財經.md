# 中國香港保單稅務、美伊臨時安排與AMD財報｜小翠時政財經

**日期**：2026年8月5日（美東時間）  
**影片**：https://www.youtube.com/watch?v=eG4NrYSvJ9o

## 重點

- **美伊海峽安排**：美國媒體報導，美國、伊朗與阿曼接近達成為期60天、可延長的臨時安排；海灣進港航線經伊朗水域、離港航線經阿曼水域，暫不收費，並討論在30天內清除航道水雷。當時協議尚待正式公布。主持人認為即使達成安排，仍有被撕毀的風險。
- **美國就業與消費**：7月ADP私營部門新增職位4.4萬，低於前月9.5萬及市場預期。主持人形容就業市場僵持：找新工作較難，但在職者暫未面臨大規模裁員；跳槽者薪資增幅高於留任者。迪士尼美國主題樂園客流量年增3%、人均消費年增4%，高收入家庭消費仍強，與前一日麥當勞反映的低收入消費疲弱形成對照。
- **亞洲股市與記憶體**：日經、韓國、台股隨美股反彈。SK海力士董事長個人買進公司股票，公司也計劃回購；主持人認為股東回報與訂單能見度對股價有支撐。她指出韓國槓桿ETF交易量及散戶融資餘額已較高點下降，但仍提醒不要加槓桿。
- **AMD與SpaceX財報**：AMD第二季營收年增50%，每股盈餘1.66美元，第三季營收指引中值130億美元，高於分析師預期但未達最樂觀預期。主持人認為需求強，但股價已反映較高成長期待；台積電先進封裝產能是供給限制之一。SpaceX第二季營收78億美元、年增92%，Starlink收入42.9億美元；AI雲端收入增長，但資本支出達183.7億美元，超過當季營收兩倍。主持人認為成長與投入並存，估值仍不便宜，不會以長期投資方式買入。
- **中國與港股消息**：節目談及內地居民香港保單的境外收入稅務，主持人將其視為既有稅務規定加強落實，而非確認一項新稅法；也討論中國反制美國措施。相關細節以節目所引報導為準。
