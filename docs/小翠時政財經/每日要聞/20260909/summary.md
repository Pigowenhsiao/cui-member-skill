# 【每日要聞】油價升破100美元、美加貿易摩擦升級，貝森特強硬喊話，OpenAI需求有多強？

**日期**：2026-09-09（美東時間）  
**影片**：https://www.youtube.com/watch?v=8s7D9GmHPEU

## 內容摘要
美軍稱摧毀五艘伊朗油輪，伊朗亦宣稱報復，令市場擔心衝突擴大，油價升破每桶100美元。加拿大對美國商品加徵反制關稅後，美國宣布限制部分加拿大商品進口。節目另談貝森特對日圓及美國財政政策的強硬表態，以及ChatGPT新模型帶來的需求增長、AI安全與資料使用爭議。主持人認為新模型正推高AI使用與算力需求，但也凸顯企業責任和監管問題。

## 重點整理
- **伊朗衝突與油價**：美軍表示摧毀五艘伊朗油輪，以回應伊朗此前向美軍艦艇發射導彈；盧比奧稱若伊朗繼續攻擊，美方將繼續打擊油輪。伊朗宣稱擊中美艦及油輪，美軍否認。主持人認為即使相關宣稱未獲證實，緊張言論仍會推高風險溢價，油價已升至每桶100美元附近或以上。
- **美加貿易摩擦**：加拿大對約200億美元美國商品加徵15%至50%關稅生效；美國宣布自9月29日起禁止部分加拿大酒類、乳製品及摩托車進口，並將部分加拿大商品移出聯邦採購目錄。節目指出加拿大烈酒出口高度依賴美國市場，貿易摩擦將增加企業尋找替代市場的壓力。卡尼呼籲民眾支持本國商品及旅遊。
- **貝森特的政策訊號**：貝森特表示正與白宮預算部門制定財政整頓計劃，並談到合法移民仍有助美國吸引人才。他以「我是莊家」等強硬說法警告市場參與者，並稱可用美國資產負債表服務外交政策；主持人將其解讀為對日圓空頭的威懾，以及美國支持盟友的訊號。
- **匯率與美債的差異**：主持人認為，日圓干預能靠美日協調及市場空頭平倉產生短期效果；美債收益率則取決於發債規模、通脹及利率預期，單靠財長喊話或短期回購無法解決財政紀律問題。
- **OpenAI使用增長**：新模型帶來用戶需求上升，OpenAI表示部分高活躍企業客戶的使用量大幅增加，企業客戶、周活躍用戶及使用任務種類均呈增長。節目指出算力仍受限，個人訂閱可能受到容量安排影響；主持人認為模型能力改善能帶來更多應用和商業需求。
- **AI研究、隱私與監管**：節目談到OpenAI據稱以未公開模型處理納維-斯托克斯方程難題，引發其是否利用研究者使用產品時留下的資料、搶先研究成果的倫理爭議。主持人亦提及AI安全研究人員離職的疑慮，認為AI應視為工具，風險關鍵在於使用者的指令、資料治理與權力集中，而非模型必然自主毀滅人類。
