# 【每日要聞】伊朗威脅擴大報復、墨西哥擬限制中國商品；AI與半導體回調下的市場觀察

**日期**：2026-08-19  
**影片連結**：https://www.youtube.com/watch?v=OC225e0zJpY（原摘要所列，尚未能由逐字稿核對）

## 內容摘要
節目先談伊朗與阿曼擬公布新的霍爾木茲海峽通道，並引述報導指出，若美國再度升級軍事行動，伊朗可能攻擊東南歐的美國軍事資產，甚至海底光纜。主持人也提到墨西哥研究對中國等國的部分商品提高關稅；特朗普在習近平訪美前公開FBI調查「方方」案卷，主持人認為此舉主要是攻擊民主黨、同時向中方傳遞政治訊號。

市場方面，主持人將近期股市回落視為漲多後的調整，提醒勿把事後拼湊的宏觀利空當成下跌原因。討論涵蓋美國長債拍賣與聯準會會議紀要、AI資料中心監管、半導體股回檔，以及韓國晶片企業提高股東回報、台積電先進製程進展和日本半導體人才短缺。節目也談到大型科技企業面臨的監管與商業風險，並以中國股市重挫及杭州政商飯局性侵事件為例，評論投資環境與社會問題。

## 重點整理
- **伊朗局勢**：伊朗議員稱將與阿曼公布新的霍爾木茲海峽通道，並可能收費。媒體報導指，若美國再攻擊，伊朗可能以保加利亞等東南歐國家的美國資產及海底光纜為報復目標。
- **中國貿易與政治**：墨西哥正研究提高部分中國商品關稅，鋼鐵、汽車等可能受影響。主持人認為，特朗普在習近平訪美前公開「方方」案卷，主要意在攻擊民主黨並為中期選舉造勢。
- **美債與市場**：節目關注160億美元20年期美債拍賣及聯準會7月會議紀要；主持人認為市場常在下跌後補上理由，短線回檔不等於長期趨勢反轉。
- **AI基建與半導體**：主持人認為賓州資料中心規範雖提高電力、社區及用工要求，但不至於扭轉算力需求。亞洲股市走弱之際，SK 海力士宣布大額庫藏股回購並擴大股東回報；三星上調部分晶圓代工價格，反映產能需求強。
- **產業與監管**：日本半導體擴產受人力短缺及企業較保守的投資習慣限制。節目另談Meta面臨的訴訟風險、蘋果因歐盟監管調整App Store抽成，以及甲骨文資料中心天然氣管線改道。
- **中國市場與社會議題**：A股大跌、宇樹科技上市首日大幅上漲，主持人批評市場資金有限、投機性強；節目亦評論公積金利率決策調整及杭州國企房產相關人員飯局性侵事件。
