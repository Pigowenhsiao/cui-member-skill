## 宏觀與國際

- 油價下跌帶動美債殖利率回落、股市上漲。布蘭特原油約98.74美元、WTI約93.50美元。媒體引述伊朗高級官員稱，若美方先緩解軍事壓力，伊朗願於七天內重開霍爾木茲海峽；革命衛隊稱符合國家利益時應談判。沙特延布港裝運及東西向輸油管道預計本週恢復。
- 川普組建中東能源重建基金PATC，美國投入50億美元、八個中東國家合計匹配50億美元，由美國國際開發金融公司（DFC）管理。公開用途為修復戰爭受損煉油廠；主持人認為另有建設繞過霍爾木茲海峽能源出口路線、降低伊朗影響力的戰略目的。
- 川普與CNN、MSNBC、Politico等媒體衝突：三家媒體記者被撤銷白宮通行證，媒體池其他成員拒絕代班，三家媒體提起訴訟，主張涉及第一修正案及正當程序。白宮稱新聞池進入資格是特權；白宮另推出24小時「川普TV」。
- 加拿大央行行長警告第四季經濟增長可能低於1%、通脹約3%，存在滯脹風險。德國梅前州選舉中選擇黨得票38.2%居首、基民盟僅4.9%；柏林極左政黨亦居首，支持收回大型房企住宅作公有。相關政治評述為主持人觀點。
- 路透社引述消息人士稱，習近平可能在川習會要求停止對台新軍售及交付已訂購武器，並以協助美方施壓伊朗作交換；節目提及一筆約140億美元軍售仍待川普決定。主持人認為此要求難以交換到美方利益，國會鷹派支持對台軍售，實際政策走向未定。
- 貝森特接受CNBC訪問，主持人歸納七點：他信任沃什但不認為核心通脹已明顯升溫；能源價格是債務利率壓力來源之一；國債回購目的為修正市場失序而非釘住利率；批評Meta等AI公司應承擔自身產品風險；美中AI溝通渠道已建立，預計兩個月後在深圳續談；非敏感商品或有部分關稅豁免、休戰或延長半年；9月23日起加強針對伊朗航空公司及供油、地勤、售票服務的制裁。

## 市場、資產配置與AI

- 比特幣升至約85,000美元、創八個月新高，五日漲逾7%，三個月漲近35%；現貨比特幣ETF連日流入。主持人將走勢歸因於油價回落帶動風險偏好、數字證券監管訊號及空頭回補等因素。
- 美國家庭股票占淨資產比例升至39.9%，自2022年以來增加12.6個百分點；住宅房地產淨值占比降至19.3%，為2021年以來低點。主持人認為股市吸引力及AI投資主線、房屋維護成本等影響資產配置，並指出此為其投資看法。
- 標普全球調查179家金融機構，受訪機構稱AI目前約降低4%成本，預計2028年降幅可達6%至8%；84%將AI用於後台與自動化。主持人稱AI應用也可能成為信用評級考量。
- Meta的Muse個人AI助手主打比價、電話及日常事務處理。主持人認為其可能減少金融服務資訊不對稱、迫使銀行、券商及保險業改善服務；但商家可能拒接AI來電，Meta因而使用人工承包商代打，帶來成本與個資安全疑慮。
- Muse引發市場對消費級AI及CPU需求的預期。主持人談到Google、Amazon可能跟進個人助理，Arm等CPU相關股受惠；Meta也因Muse相關題材走強。OpenAI與Anthropic持續競爭、降價並推出模型，主持人認為美國閉源模型降價將削弱中國大模型的低價優勢。DeepSeek及月之暗面等遭中國網信部門調查，原因是Anthropic報告所稱資料外流；調查內容及後續處置仍待確認。
