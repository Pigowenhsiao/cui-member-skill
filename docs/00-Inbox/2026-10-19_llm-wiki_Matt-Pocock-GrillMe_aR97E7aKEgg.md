## 核心摘要（繁體中文）

Matt Pocock（MapleCock）在 GitHub 上的開源 AI 開發 Skill 專案已累積 16 萬顆星、700 萬次下載。核心爆紅原因是「Grill-Me」這個 Skill——在動手寫程式之前，先讓 AI 反過來把你嚴格拷問一輪，強迫你想清楚再行動。但多數人只盯著 Grill-Me，忽略了整個專案其實是 Matt 多年 AI 開發經驗的集大成。影片依序拆解各個 Skill 的配合邏輯，並與 Superpowers 進行比較。

---

## 關鍵重點

1. **Matt Pocock 的核心問題**：AI 本質是充滿隨機性的黑盒子，他的終極目標是**控制 AI 的隨機性**。

2. **Grill-Me 的設計理念**：在寫 code 前先讓 AI 對你進行蘇格拉底式詰問，一題一題逼到你「完全扛不住」——強迫你先想清楚再做。

3. **為何市面框架不夠好**：Gash-It-Down、Spec-Kit、Superpowers 等大框架太複雜，Matt 想要更輕量、更可控的方式。

4. **Skill 套件的結構**：從寫規格（Spec）→ 拆任務 → 寫 code → 測試，全部串聯，每個環節都有對應 Skill 管控品質。

5. **與 Superpowers 的核心差異**：Matt 的專案強調「AI 對人的反向約束」，而非「人對 AI 的正向引導」；Superpowers 偏向引導式，Matt 偏向挑戰式。

6. **推薦策略**：
   - 有一定開發經驗，想提升 AI 協作品質 → Grill-Me 體系更適合
   - 新手，需要更多引導 → Superpowers 這類引導式框架更友善

7. **Matt Pocock 的定位**：TypeScript 領域最頂尖的老師之一，他把完整的 AI 工作流開源，等於把自己的編程功力打包進整個項目。
