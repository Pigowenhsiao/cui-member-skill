## 美債殖利率與股市關係深度解析

### 三種驅動因素與不同意義

| 驅動因素 | 對股市影響 |
|----------|------------|
| 實際利率溫和上升（經濟強勁） | **股債同漲**（企業賺錢抵消PE下壓） |
| 通膨預期爆炸 | **聯準會必加息 → 股市跌** |
| 政府發債過多→期限溢價上升 | **影響中性**（股市不靠發債） |
| 經濟復甦告別低息時代 | **股債同漲**（資金從債市流向股市） |

### 歷史案例
- **90年代後期**：10年期國債5-7%，經濟互聯網時代 → **股債同漲**
- **2023年**：國債5%，全年股市大漲 → **AI蓄勢啟動，公司EPS增速抵消PE下壓**
- **2016-2019川普任期**：國債和股市同漲 → **經濟強勁**
- **核心公式**：股價 = EPS × PE；PE被國債收益率下壓，但**若EPS增速 > PE下壓速度，股價仍漲**

### 「輝達奇蹟」
- 輝達PE一路下行，但股價穩步上漲
- 原因：EPS增速足夠快，對沖了PE下修壓力
- **例子**：若EPS 10→13元，PE 30→25倍，股價仍從300→325元（+8%）

### 甲骨文的極端性
- 基本面無惡化，EPS仍超預期成長
- 槓桿加得最高（追赶者）
- 跌至110元≈13倍PE，接近「破產定價」
- **結論**：這是極端事件，不代表基本面有問題，未來修復會很快；抄不好很正常，不要拿這次當經驗複製

### 持股紀律
1. **不要全部重複持倉**：有輝達就不用買AMD（同赛道）；有微軟+谷歌就不用買亞馬遜
2. **分散赛道**：上中下游都要有，東邊不亮西邊亮
3. **不要盯盤**：每天盯盤只會讓情緒崩潰，心臟受不了；掛現價單後去生活
4. **不對沖**：短線對沖浪費成本，看長線公司基本面
5. **不要後悔**：早知道不可能這麼多，如果能猜到市場頂底早就是巴菲特
6. **付出時間成本是對的**：提前佈局，位置低，持股體驗好，道心不動搖
