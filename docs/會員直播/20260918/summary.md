## 投資方法論：價值投資第二課

### 一、建立主線思維
- **主線定義**：投資者需先確立自己的投資主線（如：押注 AI 產業爆發）
- **主線示例**：AI 模型越來越強 → 推理需求上升 → 雲廠商持續購買 GPU、擴建資料中心 → 上游行業獲利

### 二、如何知道自己錯了——避免「偶像崇拜」
- **偶像崇拜定義**：投資者因持有某股票而自我洗腦，拒絕承認基本面已變化
- **常見錯誤**：股價下跌立刻認為自己判斷錯誤；股價上漲則信心爆棚
- **核心原則**：
  - 股價漲跌 ≠ 投資邏輯變化
  - 每天盯盤會造成心理衝擊，建議心理承受能力不足者「關幾個月再来看」
  - 「如果股票讓你每天都這麼難受，你不如把它割掉」

### 三、股價與基本面的區別
| 類型 | 說明 |
|------|------|
| **PE 變化** | 市場情緒、流動性等因素影響，屬於「噪音」 |
| **EPS 變化** | 公司實際盈利變化，會在財報中清晰體現 |
| **關鍵結論** | 短期股價波動常會漲過頭或跌過頭，不能作為判斷依據 |

### 四、追蹤關鍵變量（Key Variables）
- **步驟**：將自己投資的行業關鍵變量寫下來，每次看到新聞時對號檢視
- **半導體/AI 關鍵變量示例**：
  - 下游行銷雲廠商的資本支出是否下調
  - GPU 需求與資料中心訂單變化
  - 存儲商庫存是否開始積壓
  - 上游設備/原材料供應是否受阻（如：日本設備出口限制）
- **判斷原則**：
  - 若關鍵變量未變，只是情緒或外部因素（加息、政治因素）導致股價下跌 → **估值問題，非基本面問題**
  - 若關鍵變量發生變化 → **重新評估**

### 五、投資錯誤的三層次

| 層次 | 錯誤類型 | 應對方式 |
|------|----------|----------|
| **第一層** | **價格錯誤**（股價短期下跌） | 不重要，不應據此判斷對錯 |
| **第二層** | **關鍵變量改變**（需求增速放緩、毛利率下降、出現強勁新競爭者） | 重新評估，但不必馬上得出結論 |
| **第三層** | **因果鏈斷裂**（核心假設出問題） | **及時反省，果斷調整** |

**因果鏈斷裂示例**：
- 原邏輯：AI 模型越強 → 算力需求越大
- 斷裂情況：模型越強但算力需求反而下降 → 核心假設出問題

### 六、行業判斷 ≠ 個股判斷
- **常見誤區**：看好一個行業就以為所有公司都會受益
- **新能源案例**：行業增長正確，但產能擴張速度快於需求 → 價格戰 → 企業賺不到錢（連特斯拉也賺不到錢）
- **關鍵提醒**：
  - 行業好 ≠ 每家公司都好
  - 盡量不買虧損公司（若所有人都賺錢，某公司卻一直虧損，一定有問題）
  - 「你不能二十家機器人公司都買，有些公司經營很差，哪怕行業很好它也不行」

### 七、研究方向
- **除了行業基本面，還需研究**：
  - 現金流：公司實際現金狀況
  - 資金流向：利潤爆發點在哪裡、增長在哪裡、資本回報率在哪裡
- **不要只看到大故事就默認所有企業都會受益**

### 八、應對而非預測
- **核心觀念**：不要試圖預測市場（明天漲跌、何時上車），要提前想好應對策略
- **應對思維**：列出未來可能出現的多種情況，每種情況出現時的應對策略是什麼
- **主持人經驗**：無法在 6 月預測 7 月一定見底，而是在觸發應對機制時才通知觀眾
